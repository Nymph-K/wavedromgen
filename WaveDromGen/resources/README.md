# resources

- `skins.json` — WaveDrom's official skin symbols and CSS styles converted to
  JSON. Generated from the `wavedrom` npm package 3.8.0. MIT licensed; see
  `../../THIRD_PARTY_NOTICES.md`.
- `app.ico` — application icon copied from the original WaveDromGen repository.

The skin file is loaded by `WaveDromGen/skins.py`. It contains four skins:
`default`, `lowkey`, `narrow` and `dark`.
